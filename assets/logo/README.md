# SessionBuddy logo assets

Selected direction: **Agenda fold** — an agenda row folding into an `S` and ending with a forward cue.

## Formats

- `svg/`: editable masters for product UI, print, and future exports.
- `png/`: transparent raster exports at common favicon, app-icon, and presentation sizes.
- `ico/`: multi-purpose browser favicon.
- `pdf/`: high-resolution handoff files for print and presentation tools. Use the SVG masters when editable vector artwork is required.

## Recommended files

- Product navigation: `svg/sessionbuddy-lockup-color.svg`
- Compact UI/app icon: `svg/sessionbuddy-icon-color.svg`
- Browser favicon: `svg/sessionbuddy-favicon.svg` with `ico/sessionbuddy-favicon.ico` as fallback
- One-color printing: `svg/sessionbuddy-lockup-mono.svg`
- Dark backgrounds: `svg/sessionbuddy-lockup-reversed.svg`

The `png/` folder includes color app-icon sizes from 16–1024 px, three horizontal lockup sizes, and 512/680 px monochrome and reversed exports.

## Clear space and minimum size

Keep clear space around the mark equal to one quarter of its height. Use the icon at **16 px or larger** and the horizontal lockup at **120 px wide or larger**. Do not recolor individual strokes, stretch the artwork, add effects, or place the color icon on a competing blue-violet background.

## Brand colors

- Session blue: `#4B5FCA`
- Cue lavender: `#C5CEFF`
- Ink: `#182230`
- White: `#FFFFFF`

The horizontal SVG lockups use an `Inter, Arial, sans-serif` font stack for the wordmark. Convert the wordmark to outlines before sending artwork to vendors that cannot guarantee the font.
