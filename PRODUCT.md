# SessionBuddy product context

<!-- impeccable:product-schema 1 -->

Purpose: product constraints for interface work. Lifecycle: approved. Authority:
repository instructions, executable product contracts, and the user-approved
reference redesign. This record does not change capability or release status.

## Platform

web

## Users and Purpose

SessionBuddy supports organizers managing calls for proposals, reviewers assessing
submissions, speakers preparing participation, and visitors discovering events
and published schedules. Preserve these existing roles and workflows.

## Capabilities and Constraints

The capability boundaries are platform, console, CFP, evaluation, speaker
operations, and scheduling. `docs/product-status.md` owns current implementation
and verification status; this document does not supersede it.

The Engine Room is internal, not a customer homepage. Authentication,
authorization, tenant isolation, final-decision immutability, private uploads,
and truthful saved/error states remain unchanged by visual design.

## Brand Commitments

Keep the SessionBuddy name, factual content, and functional affordances. The
user-selected TaskFlow calendar dashboard is the visual reference:
https://dribbble.com/shots/27112768-TaskFlow-Team-Calendar-Event-Management-Dashboard-SaaS-Web

Adapt that reference to existing workflows rather than adding TaskFlow features,
commercial claims, or invented product data.

## Product Principles

- Make the user's next action and current state clear.
- Keep uncommon detail secondary without removing necessary controls.
- Use consistent navigation and controls across role-specific surfaces.
- Preserve working behavior and report verification limits honestly.

## Accessibility and Inclusion

Support desktop and mobile, keyboard navigation, visible focus, semantic labels,
readable contrast, and reduced motion as required by repository instructions.

## Open Decisions

No new capabilities, deployment, or data migration are authorized by the visual
redesign. Long-term positioning beyond existing product documentation is not
defined here.
